# Bounded native edits for large documents

10 October 2026. Item 3 adds bounded native edit transport and patch 0015. The production fixture enables delta mode before activating the Cocoa client. A message contains the changed UTF-16 range, expected removed fragment, replacement fragment, global selection/marked ranges, sequence and originating client. Cocoa retains the global document context, so existing substring, hit testing, range geometry and IME replacement coordinates keep their document meaning. Legacy snapshot APIs remain available for earlier deterministic contracts.

Native editable documents are capped at 4 MiB of UTF-8; each removed/replacement fragment is capped at 4096 bytes. Even worst-case JSON escaping of both fragments fits the 64 KiB message limit. Oversized native edits are audibly refused before native mutation. This is a prototype support boundary; larger documents relinquish native activation and large native insertions require a later chunking/paste policy. Existing non-native editing paths keep their existing policies.

The UI keeps a shadow only after an acknowledged publication succeeds. Queued deltas advance that shadow in order, then use the existing atomic whole-document expected-text comparison for the exact buffer. A shared edit anywhere in the document invalidates the comparison, including edits outside the small delta range. Composition cancellation, dirty flags and one net undo transaction retain the adapter's existing behavior. Decoding retains only queried scalar boundaries rather than a per-rune hash map.

This bounds transport and diagnostic retention; it does not bound total edit computation. Cocoa comparison and the current Go exact-buffer/undo/shaping path still inspect or copy the document. Whole-document native context, Go rune/grapheme metadata, font and GPU ownership are separate memory costs. Production-scale timings and resource gates are item 5.

A two-megabyte hidden Cocoa document accepted three queued edits before acknowledgement, with a maximum encoded message of 209 bytes, and refused a 4097-byte insertion without changing text, selection or sequence. Toolkit integration tests exercise a two-megabyte exact buffer, multiple queued preedits, cancellation and an outside-range shared edit. Tests cover nonzero global ranges, surrogate interiors, expected-fragment mismatch and worst-case escaped message credit. Prism's redundant decoding finding is fixed; bridge and toolkit changes are reviewed separately. Evidence: prototypes/foundationintegration/evidence/20261010-large-native/. Reviews: reviews/large-native-20261010/. These deterministic calls do not establish live IME acceptance; G1 remains open.
