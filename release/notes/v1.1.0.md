# Vellum v1.1.0 — application workflows and workbench source

This source release adds the development work since v1.0.0 while preserving the
stable v1 API contract and its experimental exclusions.

## Highlights

- Compatible additions for application path, URL and sharing services, richer
  content controls, command palettes and workbench UI composition.

- Forge design workbench with a live primitive 3D assembly, expression-based
  dimensions, move/resize handles, selection, Undo/Redo and workspace persistence.
- Document starter profile and two-window Documents example with per-window
  commands, Save/Open/Save As, coordinated Quit, restoration and recovery.
- Focused document regression tests and scoped native acceptance for Unicode
  persistence, settled keyboard history, Save A / Cancel B Quit, normal restart
  and interrupted-session recovery.
- A pinned private Documents daily-evaluation launcher, guide and issue log.

See the [README](../../README.md), [Forge guide](../../examples/forge/README.md),
[document starter guide](../../docs/building-macos-apps.md), and
[document acceptance records](../../docs/reviews/document-priorities/).

## Build and verification

Clone the v1.1.0 tag, follow the README preparation steps, and build each example
from its independent Go module. The root module requires Go 1.25.6. GitHub source
archives contain checkout source, not prepared native dependencies.

Focused offscreen race tests and directory-safety tests passed for the recent
Documents qualification work. Recorded native checks used the separately
identified build24-b9212489afc9 on macOS 27.2, minimum macOS 27.0. Those app bytes
are unchanged by this source version. Historical reports retain their original
source/build identities; they are not fresh full-suite verification of this tag.
Multi-day Documents evaluation remains to be completed.

Version-checkpoint validation: root `go test -race ./...` passed all packages
except automation, whose Unix-socket binds were sandbox-blocked; a separate
`go test -race ./automation` with socket access passed. Root `go vet ./...`
and the stable-v1 API guard passed, with compatible additions and no incompatible
changes. Version metadata and local documentation links agree. Internal review
checked the coordinated version fields and retained historical artifact identities;
no runtime implementation was changed by the version bump.

## Distribution and limits

Only the root source tag is created. No native-module tag, new prepared SDK or app
bundle is published by this version. Published build13 downloads and the private
build24 candidate keep their existing identities and distribution boundaries.
Forge has no CAD kernel; custom GPU surfaces, replay, automation and broader
workbench workloads remain experimental. Human IME/VoiceOver, every physical
pointer interaction, other hardware/display configurations and Windows/Linux
remain outside the recorded qualification. Rendering and performance policy,
existing signing/notarization status and support scope are unchanged.
