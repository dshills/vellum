# Vellum v1.1.2 — stable controls and reproducible demos

Disabled managed buttons, menu buttons, checkboxes and text fields now preserve
reserved layout space. The palette example uses this adapter fix instead of its
previous appearance workaround. Live disabled state and command admission remain
enforced. No public API or native dependency patch changed.

The repository now includes a version-aware demo suite with reproducible builds,
signed-bundle verification, archive restoration and isolated document profiles.
The SDK consumer contract follows the selected stable-v1 release identity rather
than a literal v1.0.0 assertion.

## Verification and private evaluation

Focused driver and placement offscreen race tests and vet passed for the layout
fix. Operator checks passed held press, valid placement, Undo/Redo, rejected drop
and Escape cancellation. Demo build and restored-archive verification covered 19
signed app bundles. Default Prism reviews and scoped dispositions are recorded in
[the priority records](../../docs/reviews/next-five-stability/).

The matching private build25-ed4f71f49bbf SDK and five apps passed relocation,
consumer, signature, installed-byte and linkage checks. Three native Documents
sessions on macOS 27.2 covered exact Unicode persistence, Find/Replace, Undo/Redo
and normal restart. The daily launcher now selects that candidate with a separate
private profile. Multi-day human evaluation remains outstanding.

Build25 and the previously built demo suite retain their original v1.1.1 source
identities; this source tag does not rebuild or relabel those artifacts. This is
a root source release only: no native assets, native-module tags, notarization,
broader platform qualification or changes to the stable-v1 support policy.
