# Vellum v1.0.0 — macOS source release

Vellum is a Go desktop UI framework focused on macOS look and feel. This release
publishes the framework source, runnable applications and build tooling for
personal macOS use. It adopts the existing named stable v1 API contract while
retaining explicit experimental and platform limits.

## Highlights

- Mac typography, light/dark themes, proportional prose editing, full-color icons
  and a broad catalogue of input, navigation, collection and content widgets.
- Native AppKit titlebar toolbars with customization/persistence, menus, file
  dialogs, alerts, Quick Look, Colors/Fonts panels and macOS content integrations.
- Application-owned commands, bounded Undo/Redo, document persistence, recovery,
  cancellable work and multiple windows with independent native toolbars.
- Notes, Mac Widgets, Reminders and the drawing app, plus three new original
  showcase apps: **Forma** (poster studio), **Luma** (image library) and **Pulse**
  (fictional telemetry explorer). Real native screenshots are in the README.
- Corrected showcase sidebar icon alignment/spacing and scoped light/dark table
  selection, with focused model, routing and appearance regressions.

[Read the README and see the apps](https://github.com/dshills/vellum/tree/v1.0.0#see-it-in-action).
[Showcase controls and limits](https://github.com/dshills/vellum/blob/v1.0.0/examples/showcase/README.md).

## Build from the tag

Use Go 1.25.6 or the compatible version declared in go.mod, Python 3, Git,
`patch` and Xcode Command Line Tools on Apple Silicon macOS:

```sh
git clone --branch v1.0.0 --depth 1 https://github.com/dshills/vellum.git
cd vellum
export VELLUM_CACHE_DIR=/tmp/vellum-go-cache
./drivers/cogent/prepare.sh
. ./drivers/cogent/env.sh
(cd examples/showcase && go run ./cmd/forma)
# Or: ./cmd/luma / ./cmd/pulse in examples/showcase
```

GitHub's automatic source ZIP/tar archives contain checkout source. They are not
prepared SDKs and need the same dependency preparation before native builds.
The native driver and examples are separate Go modules using checkout-local
replacements. Only the root v1.0.0 tag is created by this release.

## Verification and support boundary

The committed showcase checkpoint records passing model race/vet, managed-control
offscreen routing, light/dark table styling at three DPI values, native visual
inspection and accessible actions, plus private ZIP extraction/signature checks.
Automated control routing intentionally omits unsupported custom GPU surfaces;
native rendering was inspected separately. This is not physical-pointer or human
accessibility acceptance for every new demo interaction. CI results are available
on the tagged commit; historical private v1 evidence retains its own source/build
identity and is not relabeled as fresh verification of these apps.

Personal-use native acceptance covers the recorded Apple Silicon/macOS 26.6.2
host. Other macOS versions, Intel, additional display configurations, Windows and
Linux remain unqualified; Wayland is unsupported. Human IME candidate behavior
and VoiceOver usability remain unqualified. Replay, automation, diagnostics,
custom GPU surfaces and broader workbench workloads remain experimental. Backend,
rendering/pacing defaults and release responsiveness policy are unchanged.

## Downloads and distribution

This is a **source release**. Current native app bundles, prepared SDKs and native
libraries are not attached. Their changed-payload distribution audit remains
pending, and private packages remain ad-hoc signed and unnotarized. Historical
v0.1.0-alpha.3 binary assets retain only their original scope and approval.
No signing identities, notarization or audit approval changes are part of this
release. Vellum's own code uses MIT; dependency notices and terms remain intact.
