# Vellum v1.1.1 — stable layout during palette capture

Fixes the palette-to-canvas example reflowing surrounding controls on mouse-down
and returning to its original size on release. A palette capture temporarily
blocked commands, and their disabled styling removed reserved layout space.

during capture. Callbacks and the command registry still check live admission;
commands remain blocked until release or cancellation. Idle availability updates
normally afterward. No framework API or native dependency patch changed.
