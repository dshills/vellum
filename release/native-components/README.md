# Mac source-built GPU declarations

The `wgpu-darwin-arm64` directory is notice material for archive
`786aaad8bd66fa5f7c0dd395c57ff7454838387c8aae29f33f3c6652ecec4883`.
The inventory records 80 actually compiled Cargo packages/103 units, the pinned
header submodule and the executed Rust toolchain's standard-library declarations.
It conservatively includes host/build dependencies. Compiled membership does not
prove that every crate or all bundled toolchain components survive final linking.
The retained package versions, Cargo declarations, source/VCS identities, features,
compiler targets and original notice hashes identify the evidence's scope.

All 408 notice/declaration files are copied as provided, apart from the clearly
identified standard CC0 text supplement. No copyright holder or selected license
has been manufactured. Exact repository-commit declarations fill notice files
omitted from packaged crates. For example, objc2's
[upstream license declaration](https://raw.githubusercontent.com/madsmtm/objc2/8852b424193ca41602281b3d7540d7c8ed51e49a/LICENSE.md)
links standard terms and explicitly raises an Apple SDK derivation question.
That question remains unresolved here. CC0's
[standard full text](https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt)
accompanies hexf-parse's recorded declaration, rather than an unrelated README.
The copied Rust copyright document and license directory are bundled toolchain
texts; their presence is not a claim every listed component is embedded.

The existing private SDK producer includes these release files and binds their
inventory to the matching GPU candidate in the manifest. Packaging the known
source-built archive refuses a missing or mismatched inventory. Extraction checks the
same artifact/hash/reference/count/size rules. An archive with a different GPU
hash receives no component-notice coverage claim from this bundle. Historical
SDKs without the optional record remain readable with their original audit status.

`distribution_audit` remains `pending`. Exact linked-runtime and generated-code
attribution, Go/native/font/asset rights closure, supported-platform acceptance
and the owner distribution decision remain required. This collection and its
packaging tests do not approve distribution or mark Mac completion.
