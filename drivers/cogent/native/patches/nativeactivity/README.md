# Diagnostic native API attempts

Stage 72 follows the separate host-diagnostics stage 71. Explicit
vellum_native_checks builds count admitted desktop empty-event post attempts
and held Surface Present API attempts across windows with fixed saturating
counters. Ordinary surface Present bodies are preserved separately; ordinary
counter hooks are disabled. RenderTexture no-ops never count. Injected callbacks
cover admission, panic/retirement and saturation without GLFW/AppKit/GPU work.

These counts do not establish OS wakeups, GPU completion or actual presentation.
Native integration and source-bound quiet measurements remain required. This
stage is not an idle/performance target waiver or proof of Mac completion.
