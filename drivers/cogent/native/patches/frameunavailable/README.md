# Typed unavailable composition terminals (stage 86)

A detached scalar marks a checked known surface yield through measured gpudraw,
composer and Core tracing. AcquisitionOutcome.IsUnavailable conservatively
validates the existing one/two-attempt protocol; it is not a retry promise.
Unknown/backend/view/encoder/pass/success-null/offscreen/legacy failures are not
classified. Ordinary acquisition, timing regions and native ownership are unchanged.
No automatic acquisition, timer, polling, presentation, request or history is added.

Submitted/unavailable contradictions fail closed. Source-details validation cannot
manufacture or retain availability classification: eligibility is captured from
original measured terminal metadata, and composer/Core diagnostic failures clear
it. Existing first-failure text precedence and actual draw/end order are retained.
Intermediate failed composition stays terminal under the existing trace contract.
New tickets and overriding cancel/fatal/retirement terminals cannot inherit the flag.

The public Go adapter returns DesktopCompositionError matching
ErrDesktopFrameUnavailable, without a completed frame token. It consumes the actual
trace terminal before honoring an already-canceled context, preserving identity
and request ownership. FrameSample copies the scalar; false values are omitted
from JSON. No backend error identity already reduced to strings is restored.

Applications may explicitly request another Frame after a meaningful lifecycle or
application event. Shown/focused state and this result do not prove a drawable is
ready. Automatic pending/resumption requires an authoritative availability event
that is not established here. Synthetic measured Manual fixtures are software
protocol evidence; old native failed scopes remain immutable and unqualified.
