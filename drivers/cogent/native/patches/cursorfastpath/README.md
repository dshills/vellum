# Stage 0101: reuse an already applied cursor image

Repeated cursor assignments still resolve enum, custom units, pixel size and current raster generation. A detached mutex-owned mirror allows only the exact immediately preceding successful native image on the same live, unchanged-scale window to skip pixel copying and the synchronous main queue. Standard RGBA headers are bounded before admission. Closed/stopped, failed, intervening, malformed and size/theme/scale-changing requests retain the existing path. Any explicit mode request permanently disables this optimization for that window; native-owner fields remain native-main-only. Constructor eligibility, no-op queue/allocation behavior, invalidators, stale/concurrent callbacks and stopped-main rejection have headless fake-backend regressions. Native timing remains a separate required experiment.
