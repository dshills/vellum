# Neutral icon artwork

These 13 original geometric pictograms replace unresolved supplier/custom artwork in the Core icon bundle. They preserve public filenames and Go exports, not external brand appearance. All inherit the UI fill color, use no fonts or external resources, and are MIT licensed by Vellum's author. RadioButtonPartial remains a half-filled selection; ToggleMid has a centered thumb. Latex/Tex and Make/Makefile remain byte-identical aliases.

Run `python3 -B generate.py --output NEW_DIRECTORY` and compare the 13 SVGs and manifest byte for byte. `test_generate.py` checks reproducibility and the restricted, fontless shape vocabulary. The prepared Go tests additionally render every new asset with the actual SVG/rasterx parser at four sizes and two tints, check partial-state pixels and embedded export identities, and validate the complete 4105-file provenance ledger.
