# Additional bundled Material Symbols

The three SVG files are unmodified Apache-2.0 Material Symbols from Google,
as distributed by marella/material-symbols at commit
097888d1375f87c1e9fe75ed65e20ef1cc2fb774, svg/400/outlined.
rain.svg is rainy.svg; sunrise.svg is wb_twilight.svg; partly-cloudy.svg is
partly_cloudy_day.svg. Only distribution filenames are changed.
See SOURCE.json for exact source blobs and file hashes, and LICENSE_APACHE.txt
for the full original declaration. Vellum MIT licensing does not replace it.
