draft-1 evidence contains three original failing malformed-index regressions;
draft-2 runs their exact unchanged bodies against the corrected runtime. A final
batch review covers portable geometry, native admission, independent consumer
source revisions, tests and contracts. Review input maps bind each record to
the bytes actually examined.

combined implementation/specification batch once. Its raw result, process exit,
input map and any finding adjudication are retained here. Final metadata and
qualification are checked internally before promotion and commit.
