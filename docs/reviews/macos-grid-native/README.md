original regression bodies. It checks owner/lifetime admission, retained geometry,
local native bounds, registry rollback, generated identities, inactive tab scope
and namespaced Workbench focus. The independent consumer and repository check

[original Prism result](prism-initial.json) preserve the first review. A small
follow-up Prism review covers the corrected test and these updated explanations.
Both phases retain separate commits after the final source-bound verification.
