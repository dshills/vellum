# Managed software replay review

This checkpoint integrates the public record/runner, actual routed offscreen
Cogent adapter, origin-owned widget timers, independent fixed-record consumer,
pinned native patches and SDK/gate coverage. Specifications preserve the single
process owner, explicit dependency and software-only acceptance limits.

Independent internal reviews bind frozen component source hashes, focused race
checks, patch reproduction and resolved red evidence. Integration metadata and
public module paths have a separate review. Prism reviews the completed staged
source, patches, specs and report/review descriptions using Anthropic
`claude-sonnet-5-5`. Mechanical proof/log bundles are checked separately against
original bytes rather than included as source review payload.

The final staged-input ledger records source and evidence scopes and excludes
itself from its own digest map. The final metadata review checks that exact
ledger, all evidence references and reproducible native outputs before promotion
and commit. A private clean relocated SDK verification follows the commit;
public distribution audit and broader Mac acceptance remain open.
