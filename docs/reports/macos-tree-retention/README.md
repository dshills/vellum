# Completed-outline composed native retention

This campaign repeats the all-component native window lifecycle workload on
committed bf3b1b5, after the tree completion/retained-view publication fixes.
Each fresh workspace contains every accepted UI kind, editor/history, managed
Grid and Tree, docked GPU canvas, modal and 1000 density labels. The acceptance
command additionally requires the current owner tree inspection to match an
actual completed Cocoa outline transaction and its native row metadata.

The run freezes committed source and all 6204 prepared dependency files. It uses
one owned process group, a 45-minute cooperative native deadline and 50-minute
external watchdog. Samples force Go GC every 25 cycles and apply the existing
512 MiB Go-heap and 1 GiB RSS guards. Two read-only vmmap snapshots perturb the
run and remain allocation-region observations rather than GPU-memory claims.
The fixture disables only its own geometry persistence and accesses no clipboard
or OS input/accessibility preferences. It does not hide failures by raising guards.

The process and wrapper exit zero after 1362.16 seconds. Independent validation
accepts all 1000 sequential cycle records, each with 18 completed native tree
rows and 1000 fully contained density-label frames. All cycles accept native text,
replay editor history, finish Grid/Tree geometry and open/close the modal. Final
main-loop cleanup observes no window titles, native outstanding operations,
accessibility windows or pending callbacks; callbacks have stopped.

There are 41 matching forced-GC sample records. Warm samples at cycles 100–1000
range from 44,706,080 to 49,013,928 Go heap bytes (42.6–46.7 MiB) and 367,394,816
to 383,827,968 RSS bytes (350.4–366.0 MiB). The last sample has 44,892,824 Go heap
bytes and 381,026,304 RSS bytes. The 329,665-byte diagnostic final heap profile is
preserved. Sampled ranges do not bound unsampled peaks or establish a leak-free
steady state.

The same owned process is sampled by vmmap at cycles 156 and 656. Allocated malloc
is 31.1→32.5 MiB, MALLOC_SMALL resident 26.7→28.0 MiB, physical footprint 702.2→654.8 MiB,
IOSurface resident 113.4→72.1 MiB and owned unmapped graphics resident 326.3 MiB at
both snapshots. Reported process footprint peak 743.0 MiB is a vmmap process
observation, not physical GPU allocation accounting or a newly approved budget.

The internally reviewed validator pins the exact build/run commands, commit,
complete selected source inventory, all 6204 prepared hashes, producer and human
authorization receipts. It requires the unchanged literal guards, forced-GC
flags, exact cycle/sample sequences and final native cleanup. Snapshot commands,
PIDs and raw Process headers must match the one native campaign. It rejects an
incomplete or differently configured campaign.

Observed native text acceptance counts only after the controlled model changes.
Editor history and initial Grid/Tree changes are direct owner operations. Most
standard control callbacks, hierarchical disclosure and data views within a modal
are not exercised by this fixture. Density proves native semantic frame containment,
not physical raster legibility or the requested geometry at 100% display scale.
No pacing, input latency, ordinary frame budget, five cold/warm populations,
human screen-reader, physical display or overnight-soak claim follows.
