# Menu restoration observation availability

Native-check menu snapshots now include `OriginalCaptured`. A false
`OriginalRestored` without capture means restoration was not observed. The
1,000-cycle/soak fixtures never capture the original menu; their historical raw
false values do not demonstrate a production restoration failure. Those records
remain unchanged and do not gain menu-restoration qualification.

The native services fixture explicitly requires capture immediately after its
capture request and at cleanup. Its restoration comparison, menu ownership and
production shutdown behavior are unchanged. The common serializer supplies real
JSON booleans and preserves ownership, target retirement and items.

The eight-case inert Foundation fixture exercises that serializer through cgo,
including captured/uncaptured, matching/different and owned/retired states.
Focused race, the full offscreen adapter race suite and vet pass. The actual
Cocoa services command also compiles with `vellum_native_checks`; it was not
executed. Complete source/prepared vectors stay stable across each check.

[Qualification](records/qualification.json) and the
[archive index](records/archive-index.json) bind raw receipts/logs, tested sources,
producers and internal review in [the evidence archive](records/evidence.tar.xz).
The compiled private executable is excluded and identified by its build receipt.
Saved producers retain original absolute paths. This small checkpoint uses an
internal review between Prism checkpoints; the next provider review is reserved
for the significant GPU diagnostics batch.

Actual AppKit menu restoration, physical menu interaction, the hidden pre-exit
Cocoa window, native/GPU memory, overnight and performance gates remain separate.
Live tests stay deferred while the human uses the machine. No OS settings changed,
and this does not complete Mac acceptance.
