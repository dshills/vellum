+# macOS source cost checkpoint
+
+Vellum now has an explicit native source diagnostic mode. Ordinary frame metrics
+retain their call path. The source measurements locate the current fixed-grid
+cost primarily in CPU scene rasterization, guiding the next bounded repaint
+experiment. This checkpoint implements measurement, not a latency optimization
+or completion of the Mac framework milestone.
+
+## Implementation
+
+Pinned stage 36 follows the committed empty-sprite baseline `381f031` and binds
+six changed and eight new prepared files. Known scene/sprite sources time their
+actual lazy raster and Copy calls. Scrim/insets time actual Copy calls; unknown
+sources and drawers expose explicit unavailable breakdowns. Source kinds are
+captured numeric metadata. The detailed composer draws every source once in its
+original order and submits once even if diagnostic capacity is exceeded.
+
+An opt-in GPUDrawer pointer collects actual existing-and-unchanged cache hits,
+SetFromGoImage API attempts/time, and checked logical full-input 4WH RGBA bytes.
+Begin/Read/End use separate mutex acquisitions; the originating renderContext
+and native-window ownership serialize the batch. Deferred cleanup covers source
+and drawer panic/Goexit. The backend Value API logs errors without returning them;
+the instrumentation does not invent successful uploads or failure counts.
+
+`NewFrameMetricsWithSourceDetails` accepts 1..4096 tickets. At most 32 scalar
+records span each complete ticket, including intermediate composition before
+its final armed frame. Records have composition/source ordinals and retain no
+source/widget/image/user-text references. Overflow refuses diagnostic completion
+without changing drawing. Snapshots deeply detach the nested records. Ordinary
+`NewFrameMetrics` retains its 1..65536 bound and no per-source collection.
+
+The loaded-grid flag `-perf-source-details` requires `-perf`; all record stages
+agree on the mode. The runner checks scalar schema, bounds, order, nested
+intervals, full-image attempt bytes and ticket sums. Normal warm-budget validation
+refuses detailed records, independently of profiling. Diagnostic CLI results
+always leave warm_target_met false. Raster/Copy/API costs never add to UI work.
+
+## Validation
+
+Fresh prepare and manifest/order tests pass with 6,137 prepared files. Focused
+core/composer/GPUDrawer and public recorder race checks pass three times, including
+unchanged/changed real paint pixels and copy order, actual gathered kinds,
+default-path selection, unknown availability, shared prefix/final bounds,
+cancellation/retirement, aggregate overflow, and detached snapshots. Source and
+drawer panic/Goexit tests require the exact abnormal terminal, rather than merely
+accepting an arbitrary exit.
+
+Four mutation overlays produce real assertion failures when source drawing is
+duplicated, timer cleanup is removed, the whole-ticket bound is disabled, or an
+actual cache hit is omitted. They demonstrate regression sensitivity; the old
+stage35 did not expose these diagnostic APIs. Full native adapter/commands and
+loaded-grid offscreen race, native default/offscreen vet, loaded-grid vet, runner
+and SDK packaging/check unit suites pass. These software tests do not measure
+GPU transfer or physical display behavior.
+
+Consumer author checks independently preserve 32 Python tests and 15 focused
+Go race occurrences. A qualification wrapper initially refused setup because it
+incorrectly required a root go.sum; no Go child ran. The first native reporting
+helper then used `native` instead of `native_sample` after a passing ordinary
+child. That attempt is retained and excluded from the final combined observation;
+the corrected helper completed all four final native processes.
+
+## Native observation
+
+An optimized Go 1.27.2 arm64 executable ran on the local M4 Pro with macOS 26.6.2.
+One ordinary default-mode process and three fresh detailed processes each ran

+same 400 clipped cells, stored values and geometry. The ordinary samples omit
+SourceDetails. Detailed samples are independent of ordinary warm qualification.

+the 360 changed scene images each enter SetFromGoImage. Each input is 3072×1152,

+package cogent
+
+import "cogentcore.org/core/system/composer"
+
+// MaxFrameSourceRecords bounds source observations across every intermediate
+// composition and the final armed composition of one traced interaction.
+const MaxFrameSourceRecords = 32
+
+// MaxSourceFrameMetricsCapacity bounds diagnostic retention independently of
+// the larger capacity allowed by ordinary frame metrics.
+const MaxSourceFrameMetricsCapacity = 4096
+
+const (
+	FrameSourceOther uint8 = iota
+	FrameSourceScene
+	FrameSourceSprites
+	FrameSourceScrim
+	FrameSourceInsets
+)
+
+// FrameSourceSample is a scalar observation of one composition source. Nested
+// intervals are subsets of DrawNS and RasterUploadNS, never additional UI work.
+// SetFromGoImageNS includes conversion/allocation/queue API/sampler CPU work.
+// LogicalUploadRGBABytes counts attempted image dimensions at four bytes/pixel,
+// not successful texture writes, physical transfer bytes or GPU execution.
+type FrameSourceSample struct {
+	Composition, Source                    uint32
+	Kind                                   uint8
+	DrawNS, RasterNS, CopyNS               int64
+	RasterAvailable, CopyAvailable         bool
+	ImageWidth, ImageHeight                int
+	ImageChanged                           bool
+	ImageUploadTimingAvailable             bool
+	SetFromGoImageNS                       int64
+	SetFromGoImageAttempts, ImageCacheHits uint64
+	LogicalUploadRGBABytes                 uint64
+}
+
+// FrameSourceDetails is available only through the explicit diagnostic
+// constructor. Source order is local to its Composition ordinal. Records retain
+// no source/widget/image pointers or user text. Upload failures are unavailable
+// because the existing backend image API logs errors without returning them.
+type FrameSourceDetails struct {
+	Compositions            uint32
+	UploadFailuresAvailable bool
+	Records                 []FrameSourceSample
+}
+
+func cloneFrameSourceDetails(details *FrameSourceDetails) *FrameSourceDetails {
+	if details == nil {
+		return nil
+	}
+	copy := *details
+	copy.Records = append([]FrameSourceSample(nil), details.Records...)
+	return &copy
+}
+
+func frameSourceDetails(details *composer.SourceDetails) *FrameSourceDetails {
+	if details == nil {
+		return nil
+	}
+	out := &FrameSourceDetails{Compositions: details.Compositions, Records: make([]FrameSourceSample, len(details.Records))}
+	for i, record := range details.Records {
+		out.Records[i] = FrameSourceSample{
+			Composition: record.Composition, Source: record.Source, Kind: record.Kind,
+			DrawNS: record.DrawNS, RasterNS: record.RasterNS, CopyNS: record.CopyNS,
+			RasterAvailable: record.RasterAvailable, CopyAvailable: record.CopyAvailable,
+			ImageWidth: record.ImageWidth, ImageHeight: record.ImageHeight, ImageChanged: record.ImageChanged,
+			ImageUploadTimingAvailable: record.ImageUploadTimingAvailable, SetFromGoImageNS: record.SetFromGoImageNS,
+			SetFromGoImageAttempts: record.SetFromGoImageAttempts, ImageCacheHits: record.ImageCacheHits,
+			LogicalUploadRGBABytes: record.LogicalUploadRGBABytes,
+		}
+	}
+	return out
+}

+
+Stage 36 follows empty-sprite omission. Exact input, patch and output hashes
+bind the optional native path. Ordinary ComposeMeasured and zero-value FrameTrace

+

+calls. Scrim/insets time their actual Copy calls. Unknown sources retain Draw
+time with unavailable raster/copy breakdowns. Immutable numeric source kinds
+are captured at gathering, not inferred from blending operations or live scenes.
+

+composition begins cumulative scalar image counters after Start. Begin/Read/End
+take separate mutex acquisitions; no drawer lock crosses source Draw. Deferred
+End clears the diagnostic pointer on normal return, panic and Goexit. Existing
+renderContext and native-window ownership serialize the full batch.
+

+SetFromGoImage call records attempted input dimensions at checked four bytes per
+pixel and elapsed API time, including conversion/allocation/queue/sampler work.
+This is not confirmed transfer success, queue-write count, physical GPU bytes,
+GPU execution, or display latency. The existing API logs errors without returning
+them, so upload success/failure remains unavailable. Uniform Fill and resident
+UseTexture need no Go-image attempts; unknown drawers expose unavailable counters.
+

+final compositions, with composition and source ordinals. Aggregate count/byte
+overflow refuses completion. Ticket-owned records detach from composer storage;
+public Snapshot clones the nested details. Source records retain no images,
+widgets, sources, arbitrary names, errors or user text. All source intervals are
+nested inside RasterUploadNS and do not add to TotalUIWorkNS.
