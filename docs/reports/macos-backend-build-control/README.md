# Original versus diagnostic binary control preparation

Compare the unchanged retained framework executable with the unchanged private
observer-off derivative. The [protocol](../../../tools/macos-calibration/backend/BUILD_CONTROL.md)
predeclares three pairs under four minutes and preserves every prior failed scope.
No rebuild, SDK/default or release-gate change occurs. Exact source/view/routing
and classifier verification is reused; binary hashes, executable modes, match and
controller syntax pass. Internal/Prism review precedes native execution. This
control can test representativeness, not isolate pure native library cost or
qualify the framework. Results will follow only after checkpoint commit.
