# Native input and legacy event ordering fix

10 October 2026. **The reproduced ordering failure is fixed in the integrated prototype. A shortcut now sees all 32 earlier native updates, across two batches of 16.** Later native updates stay behind the shortcut. This closes the measured ordering defect from [the foundation audit](FOUNDATION_ACCEPTANCE_AUDIT.md); G1 remains open for its other contracts.

## Change

The earlier pump kept native payloads in a bounded mailbox and rearmed one wake at the tail of the toolkit deque. A legacy shortcut already queued there could run between native batches. Raising the batch limit would only move that failure threshold.

The fixture now uses `transport.OrderedPump`. Preflight atomically reserves mailbox credit and a payload-free deferred FIFO node relative to ordinary toolkit `Deque.Send` calls, before Cocoa mutates text. Commit marks the node ready; cancellation removes it. Dequeue merges only adjacent ready nodes from the same owner, up to 16. A queued key/down/chord event ends that group, so later native records cannot overtake it. Core dispatch receives each merged custom event through the existing scene handler, which applies exactly its represented records and acknowledges credit after each application.

Patch 0010 adds the proposed opt-in `DeferredEvent`, `SendDeferred` and `UpdateDeferred` extension to the pinned Cogent deque. Its zero-value ordinary FIFO, compression and priority behavior remain covered by regression tests. An uncommitted FIFO head waits on the existing condition variable instead of spinning; priority `SendFirst` events retain precedence. An abandoned native reservation can still stall ordinary events, so producers must commit/cancel and native mutation/shutdown must remain owner-serialized. This exception and priority lifecycle events are explicit parts of the contract.

One metadata node is allocated per admitted ordered record, rather than one shared native wake. Queue-owned payload remains limited to 256 records / 4 MiB / 64 KiB per record in the fixture. Queued native metadata is bounded by mailbox admission; an in-flight batch and the coalesced latest-publication node add metadata overhead. Payload copies held by producers, native strings, application histories and ordinary toolkit events remain outside that payload accounting. `Stats.Wakes` counts created deferred tokens in this path, not the number of merged UI dispatches or OS wakeups. The audit records `native_batch_events` separately.

Replaceable caret publication stays separate from actions. Shutdown atomically removes this owner's pending deque nodes, cancels reservations, and drains already committed records in bounded batches on the quiescent UI owner. Manual drain cannot bypass a live deque boundary. A decode error is reported after all captured batch records have been acknowledged, preventing merged nodes from stranding subsequent deliveries. See [ADR 0009](../decisions/0009-ordered-native-events.md).

## Scope

This establishes FIFO order at deque admission between native ordered messages and ordinary toolkit events, with bounded native work per dispatch. It does not guarantee general scheduling latency/fairness, synchronized native shadow-state prediction across every forwarded edit, full visual bidi/range geometry, global memory bounds, or successful live IME/VoiceOver/platform/trusted-release workflows. Those earlier gates and broader text regression failures remain open; no macOS input-source or accessibility settings were changed for this fix.

Reproduce with `run.sh` to prepare/build the owned dependencies, then `check_foundation.sh <new-output-directory>`. New regression tests run with `go test -race -count=10 -timeout 90s -modfile=integration.mod ./transport ./inputbridge ./semantics` under `env.sh`. The standalone audit CLI's JSON includes both fixed and legacy-control paths.
