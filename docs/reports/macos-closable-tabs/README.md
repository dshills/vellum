# Controlled document tabs

Tabs now supports per-option Closable and a typed TabClose owner callback. A close
request preserves native selection, pages and drafts until the application accepts
removal in its next view. The last-page empty state belongs to the application.
The gallery demonstrates rejection, reopening and closing all documents; the
relocated SDK fixture consumes the public API.

Owned Core patch 0058 delegates managed closing before parent/index lookup or
native deletion, consumes the gesture and supplies the actual private button.
The nil seam retains unmanaged behavior; retired managed callbacks stay guarded.
Tab/private-button identity, immutable capabilities and atomic dialog lifetime
scopes reject stale requests. Independent Workbench roots inherit enclosing
visibility/scopes. Queued callbacks use owner snapshots and current callbacks,
without reading or modifying originating native trees during peer-window drains.
The existing reconcile traversal publishes capabilities; private artwork rebuilds
only when its presentation changes.
