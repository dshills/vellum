# Explicit execution foundation

Bounded real/manual executors and clocks are public. Tasks and document sessions
accept Executor injection. Final worker results reserve owner admission separately
from ordinary input/progress callbacks; one FIFO merges their actual arrivals.
DrainN uses the initial arrival cutoff. Worker/delivery status and synchronous
terminal accounting remain visible through cancellation, closure, panic and Goexit.
