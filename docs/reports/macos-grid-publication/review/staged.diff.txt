+# macOS grid accessibility publication checkpoint
+
+Managed grids now keep their last completed accessibility subtree readable while
+new layout is pending. Pending objects refuse actions; a completed frame publishes
+matching cell semantics and bounds together. Overlapping cells retain native
+identity within the same live binding. Replacement, reparenting and actual removal
+retire old objects. Race, native and consumer checks pass. The ordinary performance
+campaign was refused for unequal rendered workloads, so this checkpoint makes no
+latency improvement claim. Mac completion and the unchanged 4ms p95 / 6ms p99
+targets remain open.
+
+## Behavior and implementation
+
+At `f68941b`, a scroll's pre-frame refresh could publish an empty grid subtree,
+retiring visible Cocoa objects before completed layout republished them. This is
+a source-backed control-flow diagnosis; historical CPU samples do not isolate
+asynchronous Cocoa parsing or establish a promised saving.
+
+The owner now stamps each visible grid scope with binding incarnation, target and
+completed generation, pending state and copied completed pixel frames. A detached
+cache holds one completed subtree per currently visible scope, retaining no model
+or action callback. Pending publication removes focus, text-client authority and
+all actions. Unrelated controls and other ready grids publish independently.
+Namespace, parent, incarnation, visibility and close boundaries clear old cache
+eligibility. Startup without a completed frame publishes only a disabled host.
+
+Queued actions recheck owner lifetime, current model generation, measurement
+incarnation/epoch, viewport/stamp and private editor session/text. Eligible stale
+cell actions preserve the existing `ErrGridStale` error callback; pending, retired
+and geometry-only refusals remain quiet. Geometry withdrawal requests publication
+once. Same-generation geometry or editor changes invalidate completion, while an
+unchanged frame ordinal does not.
+
+Cocoa validates the entire scoped envelope before commit. Native objects reuse
+only matching live identifiers, scope/incarnation and parent. Pending state also
+refuses native action and focus selectors independently of Go. Scoped pixel frames
+commit with semantics; legacy unversioned geometry updates cannot overwrite them.
+Transport retains copied UTF-8 data directly. Detailed native text-range geometry
+keeps its separate client/text contract. Opaque object serials support inspection
+without exposing pointer addresses.
+

+specification files, and 6,139 prepared dependency files. Ten checks pass: portable

+The new groups cover detached caches, mixed scopes, startup and retirement,
+namespace/lifecycle changes, queued actions, editor previews, geometry withdrawal,

+real semantic wrapper; it does not claim full Manual Extension routing.
+
+Three faulty source overlays fail behavioral assertions: missing completed-subtree
+retention, obsolete private-editor actions, and silent geometry withdrawal.
+Production source remains unchanged during these checks.
+
+The optimized native artifact is bound to the same source/prepared map. Separate
+stored-data acceptance processes query actual attached Cocoa objects with at least

+## Refused performance campaign
+
+The same optimized artifact ran ten fresh ordinary processes: five fixed-10k and
+five fixed-million, each with 120 samples after 128 warmups. Individual native
+record validation and child exits pass. The parent campaign exits 1 and records
+`FAILED: 10k/million rendered workload differs` before launching either variable
+case. Fixed pairs 1–3 match all clips; pairs 4–5 differ at all 120 samples each.

+43 versus 12 in pair 4, and 12 versus 33 in pair 5. These yield 50 versus 51

+unproven. No runs are removed or selected, and no retry is represented as a pass.

+func (b *accessibilityBridge) prepareGridPublication(nodes []accessibilityNode, handlers map[string]accessibilityHandler) ([]accessibilityNode, map[string]accessibilityHandler) {
+	b.mu.Lock()
+	defer b.mu.Unlock()
+	if b.closed.Load() {
+		return nil, nil
+	}
+	scopes := map[string][]accessibilityNode{}
+	for _, node := range nodes {
+		if node.GridScope != "" {
+			scopes[node.GridScope] = append(scopes[node.GridScope], node)
+		}
+	}
+	cache := map[string][]accessibilityNode{}
+	replacements := map[string][]accessibilityNode{}
+	actions := make(map[string]accessibilityHandler, len(handlers))
+	for id, handler := range handlers {
+		actions[id] = handler
+	}
+	for scope, group := range scopes {
+		host := group[0]
+		if host.ID != scope {
+			continue // Framework traversal always emits the table host first.
+		}
+		if !host.GridPending {
+			cache[scope] = cloneAccessibilityNodes(group)
+			continue
+		}
+		previous := b.gridPublications[scope]
+		retained := group[:1]
+		if len(previous) > 0 && previous[0].GridIncarnation == host.GridIncarnation && previous[0].Parent == host.Parent {
+			cache[scope] = previous
+			retained = previous
+		}
+		retained = cloneAccessibilityNodes(retained)
+		for i := range retained {
+			n := &retained[i]
+			n.GridPending = true
+			n.GridTargetGeneration = host.GridTargetGeneration
+			n.Disabled, n.Focused = true, false
+			n.Actions = []string{}
+			n.TextClient, n.TextSelection, n.TextFocus = 0, nil, 0
+			delete(actions, n.ID)
+		}
+		// Descriptor labels/help remain current even while cell data are read-only.
+		retained[0].Name, retained[0].Help = host.Name, host.Help
+		for _, node := range group {
+			delete(actions, node.ID)
+		}
+		replacements[scope] = retained
+	}
+	out := make([]accessibilityNode, 0, len(nodes))
+	for _, node := range nodes {
+		if replacement, pending := replacements[node.GridScope]; pending {
+			if node.ID == node.GridScope {
+				out = append(out, replacement...)
+			}
+			continue
+		}
+		out = append(out, node)
+	}
+	b.gridPublications = cache
+	return out, actions
+}

+func axEnvelopeNodes(incarnation, target, completed uint64, pending bool, parent, value string) []map[string]any {
+	nodes := []map[string]any{

+		{"id": "row", "parent": "grid", "role": "grid-row", "actions": []string{}},
+		{"id": "cell", "parent": "row", "role": "grid-cell", "actions": []string{"press", "focus"}, "focused": true, "value": value},

+		n["grid_scope"] = "grid"

+		n["grid_target_generation"] = target

+		if pending {
+			n["actions"] = []string{}
+			n["disabled"] = true
+			n["focused"] = false
+		}

+func gridAccessibilityReady(ctx context.Context, p *perfProgram) (cogent.GridInspection, map[string]cogent.AccessibilityElement, error) {
+	for {
+		g, err := p.inspect(ctx)
+		if err != nil {
+			return g, nil, err
+		}
+		s, err := cogent.InspectAccessibility(ctx, "perf")
+		if err == nil && s.Reachable && s.NativeWindow {
+			byDomain := map[string]cogent.AccessibilityElement{}
+			for _, x := range s.Elements {
+				byDomain[x.DomainID] = x
+			}
+			host := byDomain["data"]
+			if host.GridIncarnation == g.Incarnation && host.GridGeneration == g.Generation && !host.GridPending && host.Frame[2] > 0 {
+				if _, err := checkPerfGeometry(g); err != nil {
+					return g, nil, err
+				}
+				scale := float64(g.Bounds.Dx()) / host.Frame[2]
+				visible, actual := 0, 0
+				for _, x := range s.Elements {
+					if x.Role == "AXCell" && x.GridScope == host.ID {
+						actual++
+					}
+				}
+				for _, cell := range g.Cells {
+					if cell.Bounds.Empty() {
+						continue
+					}
+					visible++
+					x, found := byDomain[cell.ID]
+					if !found || x.GridPending || x.GridIncarnation != g.Incarnation || x.GridGeneration != g.Generation || x.GridTargetGeneration != g.Generation || x.GridScope != host.ID || x.ObjectIdentity == 0 || x.Value != cell.Text || x.Name != cell.Text || x.RowIndex != [2]int{cell.Row, 1} || x.ColumnIndex != [2]int{cell.Column, 1} || x.HitTestID != x.ID {
+						return g, nil, fmt.Errorf("grid AX cell semantics/identity mismatch: %s %+v", cell.ID, x)
+					}
+					want := [4]float64{host.Frame[0] + float64(cell.Bounds.Min.X-g.Bounds.Min.X)/scale, host.Frame[1] + float64(g.Bounds.Max.Y-cell.Bounds.Max.Y)/scale, float64(cell.Bounds.Dx()) / scale, float64(cell.Bounds.Dy()) / scale}
+					for i := range want {
+						if math.Abs(want[i]-x.Frame[i]) > .001 {
+							return g, nil, fmt.Errorf("grid AX atomic frame mismatch: %s got%v want%v", cell.ID, x.Frame, want)
+						}
+					}
+				}

+		}

+	g, before, err := gridAccessibilityReady(ctx, p)
+	if err != nil {
+		return err
+	}
+	if err := verifyPerfCells(p.source, g); err != nil {
+		return err
+	}
+	reused := 0
+	for i, delta := range [][2]int{{0, 12}, {0, 12}, {96, 0}, {0, -12}, {-96, 0}, {0, -12}} {
+		_, _, err = p.scroll(ctx, metrics, delta[0], delta[1], uint64(i+1))
+		if err != nil {
+			return err
+		}
+		g, after, err := gridAccessibilityReady(ctx, p)
+		if err != nil {
+			return err
+		}
+		if err := verifyPerfCells(p.source, g); err != nil {
+			return err
+		}
+		for id, previous := range before {
+			if previous.Role != "AXCell" {
+				continue
+			}
+			if current, found := after[id]; found {
+				if current.ObjectIdentity != previous.ObjectIdentity {
+					return fmt.Errorf("grid AX recreated overlapping cell %s", id)
+				}
+				reused++
+			}
+		}
+		before = after
+	}
+	if reused < perfMinCells {
+		return fmt.Errorf("grid AX reuse fixture too small: %d", reused)
+	}
+	// Replacing the binding under the same textual Node.ID must create fresh
+	// objects, even for the same domain cell IDs and unchanged source values.
+	oldIncarnation := before["data"].GridIncarnation
+	err = p.owned(func() error {
+		state, err := p.grid.State()
+		if err != nil {
+			return err
+		}
+		p.grid, err = virtual.NewGrid(p.projection, perfColumns(), state.Config, state.Viewport)
+		if err != nil {
+			return err
+		}
+		return p.owner.Invalidate("perf")
+	})
+	if err != nil {
+		return err
+	}
+	g, after, err := gridAccessibilityReady(ctx, p)
+	if err != nil {
+		return err
+	}
+	if g.Incarnation == oldIncarnation {
+		return errors.New("grid AX replacement reused binding incarnation")
+	}
+	replaced := 0
+	for id, old := range before {
+		if old.GridScope == "" {
+			continue
+		}
+		if current, found := after[id]; found {
+			if current.ObjectIdentity == old.ObjectIdentity {
+				return fmt.Errorf("grid AX replacement resurrected native object %s", id)
+			}
+			replaced++
+		}
+	}
+	if replaced < perfMinCells {
+		return fmt.Errorf("grid AX replacement fixture too small: %d", replaced)
+	}
+	var target cogent.AccessibilityElement
+	var targetRow, targetColumn string
+	for _, cell := range g.Cells {
+		if !cell.Bounds.Empty() {
+			target = after[cell.ID]
+			targetRow, targetColumn = cell.RowKey, cell.ColumnID
+			break
+		}
+	}
+	accepted, err := cogent.PerformAccessibilityAction(ctx, "perf", target.ID, "press", "")
+	if err != nil || !accepted {
+		return fmt.Errorf("grid AX current cell press refused: %t %v", accepted, err)
+	}

+	for !selected {
+		err = p.owned(func() error {
+			state, e := p.grid.State()
+			selected = state.Active.RowKey == targetRow && state.Active.ColumnID == targetColumn && state.Generation > g.Generation
+			return e
+		})
+		if err != nil {
+			return err
+		}
+		if selected {
+			break
+		}
+		select {
+		case <-ctx.Done():
+			return errors.New("grid AX press did not reach model before deadline")
+		case <-time.After(5 * time.Millisecond):
+		}
+	}
+	_, _, err = gridAccessibilityReady(ctx, p)
+	if err != nil {
+		return err
+	}
+	return perfEmit("grid.accessibility.pass", map[string]any{"rows": g.Stamp.Rows, "visible_minimum": perfMinCells, "overlap_objects_reused": reused, "replacement_objects_retired": replaced, "native_press_admitted": accepted, "scope": "actual Cocoa stored-grid semantics/geometry/identity; not screen-reader or performance qualification"})

+		default:

+	}

+	case err := <-failure:

+	default:
+	}

+		return result
+	}
+	if _, err := cogent.InspectAccessibility(context.Background(), "perf"); err == nil {
+		return errors.New("grid AX closed attachment remained queryable")
+	}
+	return perfEmit("grid.accessibility.closed", map[string]any{"attachment_query_refused": true})

+## Managed grid publication
+
+Each visible managed grid publishes a scope identified by the native attachment,
+namespaced table ID, binding incarnation and table parent. Its ready transaction
+contains the complete bounded semantic subtree and copied pixel frames from one
+matching completed measurement. Every scoped node carries that same incarnation,
+completed generation and target generation. Native validation rejects malformed
+scope ancestry, mixed metadata and invalid frames before changing retained state.
+Ready generation equals target generation; a layout-only transition may be pending
+at the same portable generation. On the JSON wire, absent `grid_pending` means
+false and absent `grid_generation` means zero, matching Go's zero-value omission;
+present values must have their declared Boolean/unsigned integer types.
+`InspectGrid` continues to refuse pending layout.
+
+Owner publication of a new accepted projection replaces its action handlers and
+advances the bridge semantic generation. Delivery guards also refuse model or
+measurement drift before that publication. While its completed frame is pending,
+the bridge retains only the last completed subtree for the same scope, incarnation
+and parent. Those records remain readable with their previous values, selection,
+counts and frames, but are disabled, unfocused and advertise no actions or managed
+text client. Native selectors and request admission also refuse pending records.
+Inspection explicitly reports pending, target/completed generation and incarnation;
+last-completed records never count as current geometry. Initial pending layout
+publishes only a disabled table host. An unchanged pending transaction does not
+advance the global generation; a newer target supersedes it.

+Other controls and other grids publish independently during a pending transition.

+and window closure discard the old completed cache. Native objects are reused only
+for a still-live identifier in the same scope/incarnation/parent; real retirement
+cannot resurrect an object under the same textual ID. The owner cache contains
+copied bounded records, no model pointers or action closures. Completed publication
+restores current handlers and atomically updates native semantics and frames on
+the main queue, reusing overlapping visible objects and retiring departing IDs.

 ## Geometry and notifications
 
 A managed host publishes bounds after its children render with completed layout; the modal retained host publishes from its own Scene. Geometry publication copies widget state under the originating native render lock and never reenters the application owner or reads domain models. Completed geometry is cached independently of semantic publication so demand-rendered startup can publish bounds before matching native elements exist. A modal Scene shares the originating window render context, which excludes concurrent native reconciliation throughout its render pass. Cocoa converts pixel bounds through the current content view/backing scale/window screen transform, including clipped scrolled bounds. Native hit testing walks retained descendants before their parent and later siblings first, including descendants of zero-frame synthetic containers; equal-frame ties are deterministic. An active modal snapshot already excludes underlying content. Moving a native window keeps screen coordinates current. Value, tree-layout and focused-element notifications are posted after native snapshot publication.
