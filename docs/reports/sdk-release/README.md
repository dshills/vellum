# Private alpha SDK packaging evidence

The phase implements the public `vellum.Version` alpha identifier, deterministic
private SDK archives, exact checksum coverage, public release gates, relocated
consumer checks and private application layouts. The [release specification](../../../specs/release.md)
and [application tutorial](../../tutorials/building-an-app.md) describe usage.

Validation performed on macOS:

- Sixty-three Python regression checks pass: twenty-three release construction/gate
  checks, twenty archive integrity/extraction/origin checks, sixteen app packaging
  checks and four child cleanup checks.
  Changed public source, dirty source, incomplete owner/audit decisions, output
  overwrite/dangling symlinks, tampered/unrecorded/unsafe archive members and
  escaping module replacements are rejected. Public dependency fixtures also
  reject invalid cached-module verification and use freshly regenerated sources
  instead of ignored mutable trees. Universal macOS dependency headers and
  filesystems without hardlinks have focused packaging fixtures. Bounded archive
  budgets and streamed hashes have focused checks, including extended metadata
  rejection before tar parsing, PAX size/sparse framing rejection and exact unsafe/
  duplicate-member error checks. The historical archive also passes the current
  bounded path-only PAX parser without rebuilding or launching it;
  `historical-parser-check.json` records the producer SHA and current parser hashes. Source/test fixtures and nested vendor licenses
  cannot satisfy the module-own license declaration gate. SDK execution requires
  a producer digest or explicit self-attestation, replacement metadata without a
  local directory fails closed, malformed/mismatched module metadata fails before
  archive execution, the environment allowlist reduces unrelated token inheritance,
  strict Go settings block ambient modfile/overlay/configuration changes, and app
  archives normalize restrictive umasks and reject nonportable names. SDK code
  still executes with filesystem privileges; these checks are not a sandbox.
  Mocked explicit signing verifies the final path and rejects failed verification;
  no real signing identity was used. Public bootstrap/notice graph fixtures
  enforce the controlled environment and keep native source version/checksum
  provenance. Unsupported-hardlink copies are explicitly non-atomic and complete
  only after a successful producer return, before its checksum/JSON report.
  Child commands have explicit deadlines; fixed native cgo settings replace
  ambient compiler/flag overrides and proxy/TLS transport settings remain usable.
  Reserved manifest names cannot overwrite Linux executables. Outputs inside the
  source checkout or through symlinked ancestors are rejected before source reads;
  ambient toolchain-root/native metadata overrides are dropped.
- `vellum.Version` matches release metadata; the independent public API consumer
  passes Go race tests and vet. It exercises controlled values/semantic labels,
  explicit-zero styles, command availability, bounded owner commits, window
  lifetimes and docked/floating layout snapshots.
- The actual private archive contains 6,340 SHA-256 recorded regular files and
  the initial notice inventory of 89 Go modules. The subsequent classification
  fixes are covered by current unit fixtures; this historical inventory is not
  evidence that the current declaration gate passed. Every member except the
  manifest itself is recorded, including generated records. The proof records
  archive SHA-256 and the captured dirty/precommit source revision.
- The verified immutable archive was extracted into a path containing spaces.
  An independent app was generated by its own `scripts/new-app.py` and passed
  race tests, vet and a native build with `GOWORK=off`. All four local module
  replacements point inside the extracted SDK; none points to the checkout.
- A second consumer built from that same verified archive produced an unsigned
  private macOS `.app` using its extracted packaging tool. Native dependency
  inspection found only system libraries. The copied executable hash matches
  the recorded source binary. Numeric app/build bundle fields are separate from
  the alpha SDK semantic version retained in `APP_MANIFEST.json`.

The recorded private archive predates the subsequent Prism corrections; its
checksum/source records identify that precommit snapshot. JSON records explicitly
mark it as historical and not current phase acceptance; the parser digest is
local producer self-attestation and no independent authenticity is verified. The current unit
results include the later corrections. A fresh precommit snapshot is now separately validated below. A final archive will
be regenerated after the phase commits to identify clean committed source.

The historical packaging checks did not launch a native app. The fresh precommit
checks separately ran the relocated consumer and the generated unsigned app bundle
with verified GPU pixels/readback and successful process/window closure.
Windows/Linux layout fixtures do not prove target execution or runtime dependency
closure. The source archive is relocatable but still needs its external Go module
cache/network and native build prerequisites; it is not a complete offline
runtime installer.

This is a private validation artifact. Its Go-module notice inventory is not a
complete Rust/native binary/font distribution audit or legal approval. Owner
namespace/framework license choices and the distribution audit remain pending,
and public packaging fails those gates. No tag, signing identity, notarization,
remote workflow dispatch or publication was performed. A self-contained manifest
establishes integrity; authenticity requires an independently trusted digest or
signature. Target qualification gaps remain in their separate specifications.
