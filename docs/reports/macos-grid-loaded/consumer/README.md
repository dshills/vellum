# Loaded-grid consumer handoff

The final consumer CPU and Cocoa qualification records bind the eleven frozen example files, selected root/native sources and enumerated prepared fingerprints. The binary itself is excluded; its original path and SHA256 remain in the proof. Module-cache/compiler/system SDK source closure, human input/IME/VoiceOver, broad AX, performance, peak/RSS memory and private teardown completeness are not claimed.

`raw-evidence.json` preserves original logs through strict UTF-8 decode/encode round trips, including CRLF and trailing compiler tabs. Each entry carries the original SHA256/path/byte count. It is the exact raw evidence represented inside JSON, without whitespace-normalizing a log. Source snapshots and wrapper bodies are inert `.txt` files.

The initial source-bound CPU gate passed, but its first fixed-million Cocoa process exited66 with two upstream shared TextCursor races during simultaneous native closure; its functional pass stage is explicitly overridden by that failure. The variable attempt was withheld. This history is retained separately from final qualification after the backend correction. Earlier compilation/ordering failures and the wrong-cwd no-tests command remain explicitly unqualified exploratory history.

One million records store twenty int64 values each (160,000,000 logical value bytes). The measured Go HeapAlloc delta and projection index/working budgets in the full test log are scoped observations, not RSS/peak or native/GPU-memory estimates. Offscreen primitive routing and Cocoa owner-command/native-settlement workflows are separate evidence categories.
