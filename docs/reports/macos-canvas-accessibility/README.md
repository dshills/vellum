# Named canvas object checkpoint

Opt-in `ui.Node.CanvasObjects` supplies stable names/help for existing retained
Canvas2D rectangles. The managed adapter derives selection and clipped bounds
from a detached completed paint; exact-ID semantic press, pointer selection and
Option-key traversal share the owner-held selection path. The independent
placement demo exposes the API together with existing placement/history controls.
See the [contract](../../../specs/canvas-accessibility.md).

Scope checks cover four dp scales at owner batches 1/7/64, overlapping and clipped
objects, pending last-readable publication, queued native-callback admission,
model/metadata/replacement/modal/disabled/capture/window retirement, real ancestor
scrolling, retained ancestor/dialog/Workbench transfer hooks, namespace focus and
public snapshot detachment. Inert Cocoa fixtures inspect roles, hit order and
atomic pending/completed/retired elements without an OS window. Public consumer
and SDK relocation checks exercise the packaged API. Frozen professional-workspace
records remain a compatibility check. Exact source/check/review receipts are
retained with this checkpoint; failed fixture iterations are excluded from acceptance.

Internal review and one Prism review using Anthropic Claude Sonnet 5.5 precede
commit. Last-completed caches retain copied values, never action closures; scope,
frame and capture epochs protect queued actions across state changes. Drag previews
and grid decorations do not become accessible document objects.

No native executable is launched, no input sources or OS accessibility preferences
change, and no publication/signing occurs. This checkpoint does not qualify live
AppKit attachment, physical pointer input/cross-display transforms, human VoiceOver,
GPU MeshCanvas semantics, offscreen object navigation, multi-selection or complete
P3/P4/P6/P9/P11/Mac acceptance. Physical placement verification remains separate.
