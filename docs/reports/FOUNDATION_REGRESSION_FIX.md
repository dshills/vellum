# Foundation regression baseline repair

10 October 2026. Item 1 of the five-item foundation follow-up is implemented. Patch 0013 fixes tree JSON decoding; the canonical pinned tree/parser, lines/editor, core UI and full `text/...` regression suites pass. G1 remains open.

The JSON decoder created NodeBase placeholders and replaced them while encoding/json still held the original interface-slice elements. Nested children could retain the placeholder type, causing lexer Rule assertions to panic. The same panic on the editor render thread left its TestBase waiting for a shown window and eventually timing out. Decode child records explicitly into completed typed roots, then attach them to their parent. Metadata is decoded structurally rather than by byte offsets, preserves case-insensitive child names, validates declared child count, and protects the reflection-type cache across independent concurrent loads.

A regression checks node types across the embedded language grammars. Existing JSON round-trip tests now pass; a new test covers reordered/indented/lowercase metadata, invalid counts/types, parent identity and concurrent independent loads. Tree/parser race tests, the entire lines/textcore suite, core UI tests, vet and integration transport/input/semantics race tests pass.

The full canonical `text/...` run passes with a five-minute per-package time budget and a temporary test modfile resolving test-only dependencies. Production dependency declarations are unchanged. The TeX image corpus takes roughly four minutes; its original 90-second budget was insufficient. Overlapping diagnostic TeX runs in the same owned checkout also shared `texput` output and produced spurious DVI/image failures. The reproduction runner locks its owned checkout, runs commands sequentially and treats every timeout/failure as failure. No golden images were modified.

Run `P0_CACHE_DIR=/path/to/trusted/cache sh prototypes/foundationintegration/check_regressions.sh [output-directory]` after preparation. It uses the prepared font cache by default and removes only its own default temporary Go cache. Do not overlap other test commands against that same owned checkout. The normal foundation remains the pinned Cogent/go-text experiment; this is an isolated local patch pending upstream acceptance.
