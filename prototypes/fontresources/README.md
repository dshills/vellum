# Deferred system-font emoji bitmaps

The measured profile attributed much of the shaper heap to eager OpenType table buffers. This owned go-text patch defers uncompressed `sbix` payloads for opt-in stable disk resources. Ordinary Resource and compressed tables retain eager behavior. The loader retains up to 256 strike headers, reads an offset pair and the requested glyph on demand, and maintains an LRU bounded to 32 records and 4 MiB of encoded records. Deferred cache records are capped at 2 MiB; a bounded offset metadata scan detects larger records at font load and selects the eager bitmap parser for compatibility. Duplicate glyph indirections are bounded to eight levels. The table reader enforces file/table bounds. Initial and deferred parsing use one private immutable disk snapshot, so replacing or modifying the source cannot mix font versions. Snapshot admission is capped globally at 32 resources, 2 GiB of backing storage, and 512 MiB per source. Each library-owned snapshot keeps one descriptor until the last font reader is collected, then cleanup releases storage and credit. Only fonts with eligible deferred tables are snapshotted. Snapshot exhaustion or copy failure uses the existing eager parser to preserve valid-font compatibility; this fallback is counted and can exceed the deferred-path Go-memory budget. Fonts that do not retain deferred readers release snapshot credit deterministically. The measured seven-script runs require zero eager fallbacks. Unix unlinks snapshots immediately; Windows cleanup removes their paths on close. The additional copy/disk/descriptor cost and nondeterministic GC cleanup are explicit tradeoffs, requiring startup/latency and long-session evaluation.

The bitmap cache budget covers internal encoded record retention. Returned bitmap data held by callers, decoded pixels, face metadata, outlines, shaping caches and GPU atlases are separate owners. This does not establish a global loaded-font budget or a complete 40 MiB shaper/application heap guarantee. Some other font formats remain eager. Source lifetime must support `StableResource`; using an ordinary closed descriptor is unsupported.

`./run.sh` prepares both owned dependencies, runs focused race tests, builds the offscreen probe, and compares patched/unmodified go-text using the same Cogent revision and corpus. It preserves embedded fonts and system fallback. Verification compares seven-script glyph coverage, font locations, mixed-direction rune geometry and decoded RGBA pixel hashes of the emoji bitmap glyphs actually returned. Glyph IDs and hashes alone do not prove full rendering or visual bidi editing. Valid larger bitmap records use eager compatibility, which can exceed the deferred-path memory target.

The observed eager probe retains about 257 MiB; the deferred probe about 73 MiB across three lifetimes and releases to about 2.5 MiB. Exact results are in `evidence/font-{eager,lazy}.json`. The 40 MiB target remains failed. Further outline/face ownership and render-cache budgets are required before G1 closes.


## Static outline follow-up

Patch 0002 defers uncompressed static TrueType `glyf` tables through the same stable-resource opt-in. `gvar` fonts retain eager parsing because variation initialization uses all outlines. The retained loca index is at most 65,536 offsets. Each parsed-outline LRU is limited to 256 entries and 2 MiB of accounted record/contour/point/component storage. Fixed map/list metadata, parser temporaries and values retained by callers are additional. Records are capped at 64 KiB, simple contours at 1,024 and simple points at 8,192 before parsing; all glyph headers and record lengths are checked at font admission, and unsupported fonts return a load error instead of silently losing outlines. These explicit limits can narrow supported unusual fonts and need a product support policy.

All glyph outlines and extents in Ubuntu Mono, Amiri, Roboto and a Selawik variable subset match eager parsing under race detection, including cache eviction. The seven-script probe additionally compares per-glyph outline segment hashes, mixed-text geometry and decoded emoji pixels. Across three isolated lifetimes, the combined deferred path retains about 27 MiB and releases to about 2 MiB. That measured corpus passes the 40 MiB isolated-shaper target; it is not a global font/atlas or whole-application memory guarantee. The font map still retains loaded faces; a global byte/face admission policy remains required for arbitrary fonts and long sessions.

The combined evidence is `font-lazy-outline.json` versus `font-eager-outline.json`; the first bitmap-only experiment remains saved separately. `foundationintegration/run.sh` installs both font patches in the native fixture so it can be tested with the full widget/render path. No Windows/Linux runtime support is inferred from portable package compilation.

Required child-outline read failures propagate to the top level and make the entire composite unavailable. A regression test injects failure in a later component and rejects successful partial geometry.
