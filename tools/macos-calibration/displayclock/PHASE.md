# Offscreen phase-analysis contract

Consume only the two sealed off/on and on/off report archives and their indexed
preparation match. Their four SHA256 values are fixed in `phase_analysis.py`.
Read selected regular members in memory, verifying the archive hash, index member
coverage, uniqueness and selected bytes/hash. Never extract or execute contents.
Reclassify every raw document through the complete unchanged display-clock parent
chain; require exact equality with both stored validations and case receipts.
Pin the eight validator/script files to original bound-plan source hashes.

Keep four runs separate, with 248 joins each: 128 warmup then 120 measured. Retain
all rows. For each input, partition receipt/acquire/first-render-submit/first-GPU/
last-render-GPU/shown; also retain the independent two-part final-present-GPU
split. Each closes to that same input's receipt latency within 1us. Present
request can overlap GPU execution and is not added to disjoint phase intervals.
Marginal quantiles must not be added. Select each actual p95 ticket by existing
nearest-rank receipt latency and accepted-revision tie break, checking its identity.
Keep Go lateness/brackets separate; no guessed Go/native target conversion.

For on cases only, bracket every native event independently in reported timestamp
and observed callback arrays. Preceding includes equality; following is strictly
later. Equal observation times resolve to the last equal callback. Require both
sides in both arrays, with no dropped input on coverage failure. Nearest reported
tick ties choose preceding. Preserve signed event-to-nearest timestamp and that
tick's actual observation delay. Count reported and observed events separately
in (final-present GPU end, shown]. Off cases get no inferred clock joins. No
cross-process timestamp matching, fitted clock lattice, pooling, overhead
calibration, optical/latch/missed-vsync proof or causal observer claim.

Pure Python/offscreen only; no screen, native launch, rebuild, setting, framework,
backend/default/SDK/app/feature or release-gate change. Output must be fresh and
must reproduce byte-identically. Focused tests, internal review and Prism using
Anthropic Claude Sonnet 5.5 precede commit. No live authority follows from analysis.
