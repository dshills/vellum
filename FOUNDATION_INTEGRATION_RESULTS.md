## Font tradeoffs and compatibility

The measured corpus holds three private snapshots totaling 216,174,732 bytes (about 206 MiB backing storage), with zero snapshot-admission/copy fallbacks. Limits are 32 snapshots, 2 GiB total backing storage and 512 MiB per source. A snapshot uses one descriptor until its final retained reader is collected. Unix snapshots are unlinked immediately; Windows paths are deleted at close. GC cleanup is nondeterministic. Copying prevents initial headers and deferred payloads from observing different source-file versions; startup cost and long-session behavior still need measurement.

Bitmap caches retain at most 32 records / 4 MiB each. A bounded offset scan selects eager compatibility when a bitmap record exceeds 2 MiB or deferred initialization fails. Eager compatibility and snapshot exhaustion can exceed the deferred-memory target. Static outline caches retain at most 256 entries / 2 MiB of accounted storage each; admitted static fonts must meet the 64 KiB record, 1,024 contour and 8,192 point limits. Glyph headers are checked at font admission; unsupported fonts return a load error instead of silently losing individual outlines. Required composite-child failures propagate to the entire outline. These local policies need an explicit supported-font decision before production.

The full native fixture retains about **56 MiB of Go heap** after forced GC. The isolated shaper result does not establish a 40 MiB whole-app bound. Font faces, variable/embedded resources, decoded pixels, shaping caches, caller-held glyph data, GPU atlases and fixture histories need broader ownership/admission policies.

## Review and validation

Each implementation area was reviewed with the installed Prism CLI: native transport/input/semantics, attachment lifetime, GPU release, font resources, build runners and distribution. Review findings drove fixes to cancellation direction, obsolete composition baselines, stale complete publications, optional Cocoa methods, UTF-16 boundaries, clipped context requests, Control-key IME routing, atomic callback publication, decoder rearming, idle persistence, saturated shutdown, keyboard/accessibility focus, immutable resource snapshots, composite failure propagation and packaging destinations/dependency validation. Final reports and dispositions are saved in `reviews/`; historical baseline findings are retained separately rather than presented as new implementation passes.

Validation includes native protocol/saturation runs, real hidden Cogent/Metal lifecycle runs, Go vet, focused race tests, font eager/deferred comparisons, strict bundle verification and relocated launch. Portable font and transport test binaries cross-compile for Windows/Linux amd64; that is compile evidence only. No OS input-source, Dictation or VoiceOver settings were changed during this implementation pass.

## Still required before foundation acceptance

1. Visual bidi navigation/selection, arbitrary and multiline native text-range geometry, and long-document behavior. Current bridge advertises only the visible insertion caret.
2. Live Japanese/Chinese candidate-panel position under scrolling, scale and focus changes, plus complete VoiceOver editing/navigation workflows on the final build. Earlier live conversion evidence remains historical and does not substitute for these checks.
3. Ordering and fairness between bounded input batches and legacy forwarded key/shortcut events; global font/render/cache and application-history bounds; full performance workloads and edit-to-present measurement.
4. Native Windows D3D12/NVDA and Linux Wayland/X11 Vulkan/Orca adapters and runtime tests on their actual hosts. Those hosts are unavailable here; the macOS adapter does not provide their implementations.
5. Developer ID notarized release and clean-machine launch without development dependencies, followed by broader upstream text/render regression suites and a supported extension/upstream acceptance decision.

These are acceptance gates, not completed checkboxes. The architecture remains Go domain/state/workbench ownership over a Cogent desktop/rendering foundation, go-text shaping and platform-native input/accessibility adapters. The patches remain proposed owned experiments, pending evidence that this reuse strategy can satisfy the remaining contracts without an unsupported permanent fork.
